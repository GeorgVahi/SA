# Адаптер среды: Codex

Читает координатор при запуске SA в Codex. Здесь только механизмы среды; требования workflow остаются в [SKILL.md](../SKILL.md), [оркестрации](orchestration.md) и остальных references.

## Вызов и инструкции проекта

- Вызов: `$sa`, `$sa audit`, `$sa fix`, `$sa full` или однозначная просьба. Это формулировки задания, а не CLI.
- Корень скилла — каталог установленного `SKILL.md` (по умолчанию `~/.agents/skills/sa`). Передавай ролям абсолютные пути references и scripts.
- AGENTS — `AGENTS.md` проекта и вложенных каталогов по правилам Codex.
- Helper-скрипты запускай доступным интерпретатором Python 3.9+ (`python` или `python3`).

## Чистая роль

Каждый новый агент получает `fork_turns="none"`, уникальное имя с run/work/phase/round и отдельный agent ID. Модель и effort не назначать.

## Слоты

Учитывай фактически свободные потоки среды, включая координатора, родителей и вложенных агентов. Неизвестный лимит означает одну линию. Capacity error — дождаться освобождения.

## Goal

Goal-инструмент Codex управляется по правилам [SKILL.md](../SKILL.md): сначала прочитать существующий goal, не заменять чужую незавершённую цель, не задавать неуказанный budget.

## Часовая доставка при неактивном чате

Для отдельно запрошенной доставки при неактивном чате найди/создай доступный heartbeat того же чата через `automation_update`; не создавай дубликат, cron или новый чат. Prompt читает checkpoint и даёт запрошенную часовую сводку без запуска конкурирующего процесса и записи артефактов. Сохрани ID в `heartbeat_id`, останови на финале. Без планировщика доставка только во время активного запуска; один файл скилла не обеспечивает фоновое исполнение при закрытом приложении.
